# Пример использования роли Hallucination Checker

## Пример 1: Проверка ответа на соответствие требованиям

### Исходный промпт:
"Напиши функцию для сложения двух чисел на Ruby"

### Ответ ИИ:
```ruby
def add(a, b)
  a * b  # Ошибка: функция умножает вместо сложения
end
```

### Анализ роли Hallucination Checker:
- 🚨 Нарушение: Функция выполняет умножение вместо сложения
- Причина: Несоответствие требованиям промпта
- Рекомендация: Исправить на `a + b`

## Пример 2: Проверка консистентности

### История диалога:
1. Пользователь: "Используй только стандартную библиотеку Ruby"
2. ИИ: "Да, буду использовать только стандартную библиотеку"
3. ИИ в следующем ответе: "Вот как можно сделать с помощью гема 'nokogiri'..."

### Анализ роли Hallucination Checker:
- 🚨 Нарушение: Использование внешнего гема при условии работы только со стандартной библиотекой
- Причина: Несоответствие предыдущим договорённостям
- Рекомендация: Предложить решение на чистом Ruby

## Вывод
Роль успешно выявляет несоответствия в ответах ИИ, помогая поддерживать качество и достоверность генерируемого контента.
